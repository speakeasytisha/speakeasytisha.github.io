03

LANGUAGE LAB

Grammar that gives you control

20 min
NOW / ROUTINE

Present simple vs continuous

Present simple: schedules, routines, procedures.

The flight leaves at 14:20.

Present continuous: happening now.

Passengers are boarding now.

FINISHED / RESULT NOW

Past simple vs present perfect

Past simple: finished event + finished time.

The passenger missed the flight yesterday.

Present perfect: past action with a result now.

The gate has changed.

REAL POSSIBILITY

First conditional

Use for a realistic future consequence.

If + present, will + base verb

If the seat is free, I will move you.

HYPOTHETICAL / PROFESSIONAL

Second conditional

Use for hypothetical solutions.

If + past, would + base verb

If a passenger felt unwell, I would call the senior crew member.

DUTY / ADVICE / POSSIBILITY

Modals

must / have to = obligation

should = advice

can / could = possibility / polite request

You must remain seated. / Could you place your bag under the seat?

SAFE REFORMULATION

Reporting information

Use simple reporting structures instead of risky long sentences.

According to the captain…

The message says that…

If I understand correctly…

Fast grammar check — instant feedback
