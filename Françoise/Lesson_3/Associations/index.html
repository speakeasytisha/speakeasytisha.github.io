01 / ROUTINES

Present simple

Use: facts, habits, duties. I coordinate events.
+ I/you/we/they work; she works.
− I don't work; she doesn't work.
? Do you work? Does she work?
Exceptions: he/she/it + -s; -ch/-sh/-o → -es (goes); consonant+y → -ies (studies). After does, the base verb returns.

FR : habitudes, fonctions permanentes. « Je m'occupe de… »
02 / TODAY'S PROJECTS

Present continuous

Use: action now or temporary project. We are restoring a canal.
+ am/is/are + -ing.
− am/is/are not + -ing.
? Are you organising a visit?
Exceptions: make → making; run → running; lie → lying. Stative verbs such as know usually stay in simple present.

FR : « en ce moment / actuellement ». Contraste : I organise events / I am organising an event this week.
03 / HISTORY

Past simple & used to

Use: completed past facts or previous careers.
+ We restored; I used to work in accounting.
− We didn't restore; I didn't use to work there.
? Did you restore it? Did you use to work there?
Exceptions: build → built; send → sent; be → was/were. After did, use base verb; used to becomes use to.

FR : passé terminé ou « avant, je travaillais… ».
04 / OBLIGATIONS

Must / have to / can / could

Use: duties, abilities, polite requests.
+ We must protect it. We have to apply.
− We mustn't damage it (= interdiction). We don't have to attend (= pas obligatoire).
? Do we have to attend? Could you send it?
Exception: must/can/could + bare verb, never *must to send*.

FR : « il faut », « ne pas avoir besoin de », « pourriez-vous… »
05 / EXPLAINING PURPOSE

To / so that / because

Use: express a goal or reason.
+ We raise funds to restore the canal. We organise visits so that people can learn.
Reason: We preserve the oven because it matters.
? Why are you raising funds?
Exception: to + base verb; because + complete clause.

FR : pour + infinitif ; afin que + proposition ; parce que + proposition.
06 / NATURAL ENGLISH

Phrasal verbs

get in touch with a donor · follow up on an application · look into a grant · set up a meeting · carry out repairs · pass down traditions.
? Could you look into this? − We haven't followed up yet.
Word order: some are separable (set the meeting up / set it up), others are not (look into it, not *look it into*).

FR : des groupes verbe + particule à apprendre ensemble.
