Spot

What are you being asked to do: identify, explain, reformulate, transmit, compare or recommend?

T

Target

Listen or read for names, dates, times, numbers, changes, reasons, actions and constraints.

O

Organise

Use a simple structure: answer first, then 2–3 useful details, then the next action.

P

Produce

Speak in short complete sentences. Check that you answered the mission—not every word you heard.

30-SECOND RESET

When you freeze, use this

1. Breathe out. 2. Say one buying-time phrase. 3. Give the answer you know. 4. Add one detail. 5. Stop cleanly.

How to use this page

  • Start in Practice mode. Read the technique before each task and use the hint only if you need it.
  • Objective questions give instant feedback in Practice mode. In Exam mode, feedback waits until the report.
  • Listening tasks allow two plays in Exam mode. Practice mode allows replay while you learn the technique.
  • Speaking tasks can record your voice locally in the browser. Written and oral work have separate trainer scoring.
  • When you feel calmer, restart in Exam mode and complete the same communication actions without support.
